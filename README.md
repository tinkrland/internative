# research

the branch where questions live before they become code.

every other branch in this repository knows its answer. this one collects the questions that
are still open, each with what has been established, what has been assumed, and what would
settle it. a note here is not a plan and not a maybe: it is a claim about the state of
knowledge, with its sources, kept where the other branches can read it.

## what belongs here

- a measurement nobody has taken yet, with the method that would take it
- a licence or platform gate that blocks a feature, named and dated
- a vendor claim that has not been reproduced, kept apart from the ones that have
- the negative results, which are the expensive ones to rediscover

## what does not

finished work (that is a branch), a wish list with no test, and anything already answered in
a README on a branch that ships. this branch is not a second brain and it is not a roadmap.

## the shape of a note

`notes/<topic>.md`, each with: the question, what is established with sources, what is
assumed, what would settle it, and the date. a note that cannot name its source is a rumour
and says so in its title.
